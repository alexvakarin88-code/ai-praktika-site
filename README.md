## Публикация
Сайт публикуется через GitHub Pages с помощью workflow в `.github/workflows/pages.yml`.
Для включения публикации в репозитории откройте Settings → Pages → Build and deployment → Source → GitHub Actions.

Сначала используйте стандартный адрес GitHub Pages. Домен ai-praktika.ru подключается отдельно после настройки DNS и проверки HTTPS.

## Принципы
- Не публиковать вымышленные кейсы, отзывы, проценты экономии или гарантии результата.
- Не запрашивать пароли, коды подтверждения и платёжные данные.
- Не подключать аналитику, рекламные пиксели и сторонние скрипты без отдельного решения.
- Юридические документы и серверную форму добавить после проверки требований к обработке персональных данных и инфраструктуры.
